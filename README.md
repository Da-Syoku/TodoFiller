# スキマス (Android)

空き時間に勉強と用事を割り振る、個人用のスケジューラです。
**素の Kotlin + Android 標準APIだけ**で作っていて、実行時の外部ライブラリはありません
（AndroidX と Material 以外は使っていません）。

## このリポジトリに入っているもの

**Androidアプリだけです。** サーバー側のコードは入っていません。

以前はバックエンド（Node.js）に配置計算とGoogleカレンダー連携を置いていましたが、
**端末内で完結する方式に作り替えました**。サーバーはもう畳んであります。

最新のAPKは [`dist` ブランチ](https://github.com/togarinozawa/TodoFiller/tree/dist) に置いてあります。
その枝は版を出すたびに履歴ごと作り直すので、古いAPKがリポジトリに積み上がりません。

## どう動いているか

**すべて端末の中で完結しています。**

- 空き時間は**端末のカレンダー**（`CalendarContract`）から直接読む
- 教材・実績・タスクは端末のSQLite（`skimas.db`）に持つ
- 配置と「間に合うか」の計算は `engine/` にある

Googleの **OAuthを一切使いません**。Googleカレンダーアプリが端末へ同期した内容に
そのまま触れるので、サーバーもトークンも、Googleの審査も要りません。

サーバーに問い合わせる実装も持っていて設定で切り替えられましたが、端末内で
不足が出なくなったので消しました。**残っている通信は、新しい版が出ていないかを
見に行く1本だけ**です（GitHubの `dist/version.json`）。圏外でも本体は普通に動きます。

## カレンダーの決まりごと

予定のタイトルの末尾でアプリの扱いが変わります。

| 書き方 | 扱い |
| --- | --- |
| `〜 家` / `〜 &h` | 家で作業できる枠 |
| `〜 外` / `〜 &o` | 外でも作業できる枠 |
| `テスト期間…` | その期間は定期テスト対象の教材だけを置く |
| `〜 %` | **アプリが自動生成した予定**。読み飛ばし、毎回作り直す |
| タグ無しの時間指定 | 埋まっている時間 |
| タグ無しの終日 | 何もしない（祝日などで1日潰さないため） |

**枠が1つも無いと何も配置されません。** まず「家」か「外」を付けた予定を作ってください。

## 画面

- **今日** — 今日の予定。完了すると実績（何問やったか）を記録する
- **単発** — 階層タスク。並び順・タグでの絞り込み・長押しで掴んでのドラッグ移動
- **教材** — 問題数と締切を登録する。「間に合うか」もここで見る
- **設定** — 起きている時間帯、カレンダーの確認、バックアップ、スケジューラ実行、更新

ホーム画面ウィジェットの「暇」から、いまの場所と空き時間を入れて候補を出せます。

## ビルド

```bash
gradlew.bat assembleDebug
```

テスト（64件）:

```bash
gradlew.bat testDebugUnitTest
```

配置ロジック・カレンダーの読み取り・一覧の並べ方は、Androidに依存しない純関数として
切り出してあります。目で見て確かめるのが一番あてにならない部分なので、テストで固定しています。

### 配布用のビルド

```bash
gradlew.bat assembleRelease -PuseDebugKey=true
```

署名鍵はリポジトリの外に置いてあり、ここには含まれていません。
**`-PuseDebugKey=true` を付けないと別の鍵で署名され、配布済みのアプリに上書き更新できなくなります**
（Androidは署名の違うAPKの上書きを拒み、端末には「アプリがインストールされていません」としか出ません）。

## 必要な権限

- カレンダーの読み取り・書き込み — 空き時間を読み、生成した予定を書き戻す
- 通知・正確なアラーム — 予定の開始時刻に、アプリを閉じていても知らせる
- インストール（`REQUEST_INSTALL_PACKAGES`）— アプリ内からの更新
